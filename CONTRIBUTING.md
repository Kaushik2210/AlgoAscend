# Contributing

Use the setup and verification commands in the [README](README.md). Keep changes focused and name the learner workflow they improve. For a lesson, include an objective, prerequisites, an example, a prediction check, and tested reference code in each supported language. Use original wording and examples or link to the source.

Run lint, types, unit tests, build, and the browser suite before opening a pull request. For UI changes, include screenshots at a narrow and wide viewport.
