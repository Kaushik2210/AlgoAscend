# Curriculum coverage

The [live roadmap](https://algoascend.vercel.app/learn) has published lessons in all 15 stages. Each lesson links to a practice challenge with tested C, Python and Java implementations. The remaining topics below are grouped by stage to track what still needs a dedicated lesson.

| Stage | Published lessons | Remaining coverage from the brief |
| --- | --- | --- |
| 00 · Computational thinking | Input, process, output, binary representation | Program execution, problem decomposition, logical reasoning, flowcharts, compilers and interpreters |
| 01 · Programming fundamentals | Loops and running totals, conditionals and functions | Types, conversions, constants, operators, scope, nested loops, debugging, pattern printing, and language-specific modules for C, Python and Java |
| 02 · Algorithmic foundations | Recursion and growth | Space complexity, Ω and Θ bounds, amortized analysis, recurrences, invariants, formal correctness and constraint analysis |
| 03 · Essential data structures | Stacks and brackets, circular queues | Arrays, strings, matrices, linked lists and variants, deques, sets, hash tables, priority queues and heaps |
| 04 · Essential algorithmic patterns | Binary search, bubble sort, prefix sums, fixed-size sliding windows, difference arrays | Linear search, binary search on answer, general two pointers, variable windows, suffix sums, frequency counting, hashing, additional sorts, merging intervals, monotonic stacks and queues, fast and slow pointers, coordinate compression and meet in the middle |
| 05 · Trees and hierarchical structures | Binary tree traversal | BSTs, AVL and red-black trees, B-trees and B+ trees, tries, diameter, lowest common ancestor, binary lifting, Euler tours, tree DP and rerooting |
| 06 · Graph algorithms | Breadth-first search, disjoint set union, Dijkstra’s shortest paths | Representations, DFS, components, cycles, bipartite testing, topological sort, additional weighted shortest-path algorithms, spanning trees, 0–1 BFS, strongly connected components, bridges, articulation points, Eulerian paths, flow, cuts and matching |
| 07 · Recursion and backtracking | Subset backtracking | Recursion trees, subsequences, permutations, combinations, N-Queens, Sudoku, mazes, constraint satisfaction and branch and bound |
| 08 · Greedy algorithms | Interval scheduling, including an exchange argument | Fractional knapsack, Huffman coding, job sequencing, additional greedy proofs and counterexamples |
| 09 · Dynamic programming | Coin-change DP, longest common subsequence | Memoization, space optimization, Fibonacci, knapsack, LIS, edit distance, grid, interval, tree, digit, bitmask, probability and graph DP, plus advanced optimizations |
| 10 · Competitive programming mathematics | Euclidean algorithm, modular exponentiation, sieve of Eratosthenes | LCM, factorization, modular inverses and theorems, combinatorics, inclusion-exclusion, pigeonhole principle, probability, matrix powers and impartial games |
| 11 · Advanced data structures | Fenwick trees, segment trees for range minima | Lazy and persistent segment trees, sparse tables, ordered sets, treaps, heavy-light and centroid decomposition, Mo’s algorithm, square-root decomposition and offline queries |
| 12 · Advanced string algorithms | KMP string matching | Rolling hash, Rabin–Karp, Z, Manacher, Aho–Corasick, suffix arrays, LCP arrays and suffix automata |
| 13 · Advanced competitive programming | XOR and bitmasks | Interactive problems, geometry, convex hull, sweep line, FFT and NTT, advanced graphs, constructive and randomized methods, optimization, contest strategy, stress testing and upsolving |
| 14 · Interview and placement preparation | Interview two pointers | More interview patterns and communication drills, timed mocks, company-style practice and behavioral preparation |
